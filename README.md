# EmployeeManager (OOPEmployeeWebApp)

Simple Java EE web application for managing employees (JSP + Servlets + MySQL).

## Prerequisites

- Java JDK 8 or newer
- Apache Tomcat 8+ (or any Servlet 3.0+ container)
- MySQL server
- MySQL JDBC driver (Connector/J) — place the jar in `WEB-INF/lib` or the container's lib directory

## Quick setup

1. Create the database (adjust name if you prefer):

```sql
CREATE DATABASE oop;
```

2. Update database properties in `src/com/oop/util/config.properties` if needed (URL, username, password, driver class).

3. Ensure `EmployeeQuery.xml` is available on the runtime classpath. The project already contains `WebContent/WEB-INF/EmployeeQuery.xml`; when building into a WAR, confirm it lands in `WEB-INF/`.

4. Build and deploy the WAR to Tomcat (or run from your IDE). Example (ant/IDE): copy the project into your IDE as a Dynamic Web Project and run on Tomcat.

## Notes and troubleshooting

- The app reads `config.properties` from the classpath (`src/com/oop/util/config.properties`). If properties fail to load, ensure the file is included in `WEB-INF/classes` after deployment.
- `QueryUtil` attempts to load `EmployeeQuery.xml` from the classpath first; if not found it falls back to a Tomcat wtpwebapps path used by some IDEs. Prefer classpath deployment.
- If you see JDBC driver class errors, update `driverName` to `com.mysql.cj.jdbc.Driver` and add the Connector/J jar to `WEB-INF/lib`.

## Common commands

Start Tomcat (PowerShell example):

```powershell
# from Tomcat bin folder
.\catalina.bat run
```

Deploy WAR: copy the built WAR to `webapps/` and Tomcat will auto-deploy.
